Excel Bookkeeping Portfolio Project

Simulate 3 Months of Bookkeeping Activity for a Delivery Driver Business

This Excel project demonstrates 3 months of bookkeeping activity for a delivery driver business using Microsoft Excel. It supports target roles such as Junior Bookkeeper, Accounting Clerk, Accounts Payable Clerk, and Accounts Receivable Clerk.

Portfolio Goal

The goal of this project is to show practical Excel bookkeeping skills for a small self-employed delivery driver business. The workbook organizes income, expenses, mileage, receipts, and summaries so records are clean and ready for monthly review.

This project uses simulated sample data only.
